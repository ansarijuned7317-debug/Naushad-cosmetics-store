Naushad Cosmetics Store

A modern and user-friendly cosmetics e-commerce website for browsing and purchasing beauty and cosmetic products online.

Features

- 🛍️ Product listing and product details
- 🔎 Product search and filtering
- 🛒 Shopping cart
- 📦 Order management
- 👤 Customer-friendly interface
- 📱 Responsive design for mobile and desktop
- 💳 Online shopping functionality
- 🎨 Modern cosmetics-focused UI

Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB

Project Structure

The project contains frontend pages, styling files, JavaScript functionality, product-related files, and backend/order management components.

Purpose

The purpose of this project is to provide customers with an easy and convenient way to explore cosmetics products and place orders online.

Installation

1. Clone the repository.
2. Install the required dependencies.
3. Configure the environment variables.
4. Start the backend server.
5. Open the website in your browser.

Status

🚀 Project is under development and can be improved with additional e-commerce features.
